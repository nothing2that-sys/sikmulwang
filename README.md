# 식물왕 (Sikmulwang)

식물 검색, 재배 기록, 물주기와 관리 이력을 기기에 저장하는 웹/PWA 프로젝트입니다. 기록은 IndexedDB에 저장되며 ZIP으로 내보내거나 복원할 수 있습니다.

공식 출처 안내는 출처와 적용 조건을 함께 표시합니다. 근거가 충분하지 않은 항목은 확정 추천으로 표시하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```powershell
cd web
npm ci
npm run dev
```

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`로 확인할 수 있습니다.
